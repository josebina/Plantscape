# 首关无代码交互分镜草案

状态：流程提案；尚未制作模型、交互原型或游戏代码，时长也未实测。植物事实以证据卡核验结果为准。

## 主情境

学生为校园中的教学庭院完成植物配置。开场先交代真实设计目标：组织入口与步道、提供季节观赏、安排背景与垂直绿化，并让植物处于适宜环境。

光照、土壤、水分、排水与空间需求在庭院中可调查，不能只表现成一排未经解释的数值滑条。温度以当地全年／冷季情境资料表达，避免用一个时刻评价长期种植。

## 时间预算

| 环节 | 暂定预算 | 控制方式 |
| --- | --- | --- |
| 任务与操作引导 | 约1分钟 | 直接演示一次观察和证据绑定 |
| 十个植物空间的短观察 | 共约5—6分钟 | 每种约30—36秒；采集关键证据，不开十套独立长谜题 |
| 三组关联推理 | 共约4—5分钟 | 约80—100秒／组；比较已收集证据，无须来回走路 |
| 庭院配置与调整 | 约4—5分钟 | 吸附放置、分层反馈、允许撤销 |
| 两个关键理由与结果 | 约1分钟 | 短证据选择，保留可选文字说明 |

总预算约15—18分钟。若无代码演练显示负担过大，应减少操作／文本或深入任务，不能靠加速阅读满足时长。

## 场景与路径

教学庭院是共同起点和终点。十种植物各有小空间，划为三个互相连接的区域；区域划分为任务组织，不代表自然分类。

- 结构区：罗汉松、棕榈、孝顺竹。
- 常绿与芳香区：木犀、栀子花、石楠。
- 花果与覆盖区：杨梅、紫荆、酸橙、扶芳藤。

每个区域内有可选路径，区域之间有回环与通用植镜通道。具体出口和地图仍待画面草图确定。植物幻想移动提供过渡体验，不成为准确识别或完成考核的操作障碍。

收集后将证据保存到随身托盘，允许跨空间对照。通行顺序可变，但三组学习要求保持一致；不因路线不同增加重复操作或遗漏计分内容。

## 分镜

### S01 读懂设计任务

画面：立体庭院的简洁全景，入口、步道、墙面与种植区域清晰可见。先显示功能目标，再按需查看生态条件。

动作：选择一个区域查看目标与条件。反馈展示“这里为什么需要某类植物”，不预先给出物种答案。

### S02 在植物空间找证据

画面：整株轮廓与两个可放大的观察位置；不依靠发光特效遮盖真实特征。

动作：翻看叶片、查看枝条或繁殖结构，从短候选中判断身份并绑定证据。证据托盘记录部位、季节与阶段。

反馈：指出证据是否有判别力；错误时引导补看结构，不只弹出“错误”。完成后获得印记与有解释的图鉴。

### S03 区分推断与事实

画面：两种植物并排，显示已采集的叶片／枝条证据。

动作：对“相近叶片是否意味着相同生态要求”等命题选择支持、反对或信息不足，并选择理由。

反馈：若只能形成假设，提示选择下一项需要的资料。经核验的生态资料成为独立补证，不通过装饰动画伪装成观察结论。

### S04 让结构与场地发生联系

画面：扶芳藤的附着结构与庭院墙面，或孝顺竹的丛生轮廓与场地视线。

动作：比较用途和约束，选一个方案，并说明至少一个必要条件。

反馈：展示条件变化后方案是否仍成立，例如支撑表面变化或种植空间不足。反事实情境不改变植物真实特征。

### S05 配置植物

画面：庭院俯斜视图，植物托盘与可调查的区域；可切换生态／功能信息层，避免一次显示全部文字。

动作：拖放并吸附，查看生态和景观两类反馈；切换成熟轮廓检查株形尺度。允许撤销与调整。

反馈：存在合理范围和多种答案。不把单一生态因素平均得分当作最终合理性；严重限制和场地功能单独提示。

### S06 用结果修正判断

画面：一个经核验资料构建的情境变化或异常案例，例如栀子花黄化。

动作：选择进一步调查的证据，再判断是否调整及如何调整。

反馈：奖赏有依据的修正；正式计分的重试政策待确定。不得以未经验证的即时萎蔫动画模拟所有长期生态影响。

### S07 解释并结束

画面：完成的景观、季相预览和简洁的学习回顾。

动作：为两处关键配置绑定证据，提交结果。

反馈：给出观察、推理、配置三个维度及可改进处，不只显示总分。彩蛋与装饰收集独立显示，不进入专业成绩。

## 移动端与视觉质量约束

- 以有限旋转的立体场景为候选，镜头不在答题中自动绕转。
- 放大关键部位；重要观察特征在小屏上仍清晰，不只依赖颜色。
- 使用温暖自然材质、柔和光影与少量神秘过渡；关键叶形、叶序和结构不得为风格化而改错。
- 每次操作尽量只有一个主要目标；桌面式多窗口和长篇图鉴不同时占据手机屏幕。
- 场景内有可辨认的尺度线索；微观放大空间注明观察尺度，避免将放大效果误认为真实株形。
- 动作与场景切换可简化，保留学习证据；最终通过目标设备验证触控和性能。

## 后续验证

先核验植物资料，再用静态分镜做完整路径演练：至少覆盖一种错误判断、一次补证和一次配置修正。检查必需证据是否可获得、任务是否可完成、合理布局是否存在、阅读量是否符合课时。之后再确定最终题目与视觉参考。
