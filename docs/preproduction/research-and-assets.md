## 来源使用范围

- 名称与分类：优先使用权威植物名录和植物志；记录采用的分类处理、接受名和异名，不混用不同处理。
- 形态与鉴别：植物志结合可确认身份的观察材料；游戏中出现的鉴别点逐项对照。
- 生态与栽培：结合可靠园艺／植物园／学术资料；适应性涉及地区时补充长沙或相近地区的栽培依据。国外气候分区不直接转换成当地评分规则。
- 景观用途：区分物种能够承担的功能与特定场地的设计判断；记录成熟尺度、物候和维护条件。
- 植物事实可归纳，但参考页面的图片和原文不自动具有游戏使用授权。

## 每条关键资料的登记字段

| 字段 | 内容 |
| --- | --- |
| 资料编号 | 与植物编号、关系编号对应 |
| 断言 | 具体支持哪项识别、生态或功能结论 |
| 来源 | 题名、发布机构／作者、URL或书目、章节／页码 |
| 查阅日期 | 实际读取日期，不能以访问失败日期代替 |
| 支持范围 | 原种／品种、阶段、地区、季节、栽培条件 |
| 限制与分歧 | 不能推出什么，不同来源是否冲突 |
| 核验状态 | 待查、已查需复核、可用于教学、可用于评分 |
| 素材关联 | 哪张照片／哪个模型部位表现该信息 |

生态数值必须保留出处、单位、适用条件与解释；目前所有精确阈值留空。关键生态判断如仅有单一、跨地区或含糊资料，继续核验，不将假精度写入评分。

## 首批素材需求

每个植物先准备整株、枝叶近景和任务所需结构；不是每种都必须制作花果全部模型。季节不足的证据可用注明日期的图鉴材料补充。

| 植物 | 必要近景／专项素材 | 需要特别确认 |
| --- | --- | --- |
| 杨梅 | 枝叶、花果／性别相关资料、季相记录 | 结果任务证据完整，不能只有果实照片 |
| 木犀 | 叶序、花部、整株及花期记录 | 品种与花期一致 |
| 紫荆 | 叶、花在枝干上的着生、荚果、季相 | 区分名称相近植物，表现位置准确 |
| 棕榈 | 掌状叶、叶柄、主干纤维、冠形 | 整株身份可靠，模型比例清楚 |
| 扶芳藤 | 附着结构、叶序、地面／攀附状态 | 品种和阶段记录，不能只用装饰藤蔓 |
| 石楠 | 叶、花序、果实、新梢 | 不混入红叶石楠等对象 |
| 罗汉松 | 叶、枝、种子与种托放大资料 | 正确结构、阶段与名称 |
| 酸橙 | 叶柄翼、枝、花、柑果 | 身份及品种；单一局部不足以鉴别 |
| 栀子花 | 叶序、叶、花、诊断情境资料 | 情境不把黄化统一归为一个原因 |
| 孝顺竹 | 秆节、叶鞘、分枝、竹丛轮廓 | 竹种正确，生长方式与尺度准确 |

共用场景素材：教学庭院、步道、墙面、地形、土壤／排水信息层、观察镜、证据托盘、植物印记和季相切换表现。共用声效：观察、收集、转移和配置反馈；环境声服务于氛围，不作为学生必须听清的计分线索。

## 素材授权与制作登记

每个拟使用资源登记：资产编号、用途、原始URL／作者、许可名称与证据、是否可修改、是否需要署名、下载日期、原始文件位置、衍生文件、植物审核状态。只有实际查验授权的资源才能标记“可使用”。

优先顺序：可确认身份且有使用权的校园素材、授权清楚的外部素材、依据核验资料自行制作。参考图、生成概念图与识别模型分开管理；概念图不能代替正确的植物观察模型。

当前资产条目均为“待收集”，尚无任何资源标记为已授权。采购、人员拍摄安排与素材预算到需要时再讨论。
